# Foundation Investment & Fund Management System

# Permission System

Each role can have separate permissions.

Permissions

- View
- Create
- Update
- Delete
- Approve
- Export
- Print

Permission can be configured module-wise.

Example

Members
    View
    Create
    Edit
    Delete

Investments
    View
    Add
    Close
    Export

Collections
    View
    Add
    Print
    Export
